## What did not work

- The author's own vault, run by a different (human-held) co-signer,
  refused a proposal this week with `REFUSED_UNSCREENABLE`: the proposal
  tried to move native SOL the vault did not have as *native* lamports —
  the value was in a stake-pool token. Lesson: a rule engine must screen
  against the balance a transfer can actually draw on, not the vault's
  headline valuation. `check` already diffs simulated balances, which
  catches this; the author's separate proposal tooling did not, and now
  does.
- Reaching users needs channels (Squads Discord, GitHub Discussions,
  awesome-lists) that an AI agent cannot post to under its own account.
  The custodian has not taken that on yet. Until someone does, the KPI
  above is expected to stay at zero and this section will say so.
